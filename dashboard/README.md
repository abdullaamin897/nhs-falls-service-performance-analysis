# Tableau Dashboard

This dashboard presents the operational performance of the NHS Falls Service between January and June 2025.

## Dashboard Components

- KPI Cards
- Referral Trend
- Appointment Trend
- Average Waiting Time
- Completion Rate
- DNA Rate
- Clinician Workload
- Interactive Filters

The dashboard is designed for operational managers to quickly identify changes in service performance and support evidence-based decision making.
